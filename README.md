📊 HR Analytics Dashboard
1. 📈 Project Title / Headline

HR Analytics Dashboard – Employee Attrition & Workforce Insights

An interactive Power BI dashboard designed to analyze employee attrition, workforce demographics, departmental performance, salary distribution, and employee satisfaction through dynamic visualizations and interactive filtering.

2. 📌 Short Description / Purpose

The HR Analytics Dashboard is a comprehensive and visually engaging Power BI report developed to help HR professionals monitor employee performance, workforce distribution, and attrition trends. The dashboard provides valuable insights into total employees, active employees, attrition count, attrition rate, average employee age, experience, department-wise employee count, salary-based attrition, job satisfaction, gender distribution, and age group analysis.

Users can interact with filters such as Age Group and Department to explore employee data from different perspectives. This dashboard enables HR managers and business leaders to identify the major causes of employee attrition, understand workforce demographics, improve employee retention strategies, and make informed HR decisions.

3. 🛠 Tech Stack

The dashboard was built using the following tools and technologies:

📊 Power BI Desktop – Dashboard development and visualization
📂 Microsoft Excel / CSV Dataset – HR employee dataset
🧮 DAX (Data Analysis Expressions) – Calculated measures, KPIs, and business metrics
🔄 Power Query Editor – Data cleaning, transformation, and preprocessing
📈 Data Modeling – Built relationships between multiple tables for efficient reporting
✨ Key Features
👥 Total Employees & Active Employees KPIs
🚪 Employee Attrition Count & Attrition Rate Analysis
🏢 Department-wise Attrition Analysis
💰 Salary Slab-wise Attrition Distribution
😊 Job Role & Employee Satisfaction Matrix
🎂 Age Group Distribution Analysis
🚻 Gender-wise Attrition Analysis
📈 Experience-wise Attrition Trend
🏢 Department-wise Employee Count
🎯 Interactive Age Group & Department Filters
🎨 Modern, clean, and user-friendly dashboard design
📊 Business Impact & Insights

4. This dashboard helps organizations to:

Monitor overall workforce health and employee retention.
Identify departments with high employee attrition.
Analyze attrition across different salary ranges.
Understand employee satisfaction across job roles.
Track workforce demographics including age, gender, and experience.
Support HR planning with data-driven decision making.
Improve employee engagement and retention strategies.
